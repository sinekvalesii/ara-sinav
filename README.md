# Ara Sınav Çalışma — 4 Ders

AÖF Lojistik ara sınavı için mobil uyumlu çalışma sitesi: Uluslararası Lojistik, Gümrük Mevzuatı, Hukukun Temel Kavramları, Türk Dili I.

Site: https://sinekvalesii.github.io/ara-sinav/

- **Notlar:** ünite ünite ezber notları, notlarda arama, ünite tamamlama
- **Kartlar:** çevir-kaydır kartlar, Leitner kutu sistemi (bilinmeyen kart daha sık gelir)
- **Test:** kaynak (tümü / 2+ sınavda / çözülmemiş / yanlışlar), soru sayısı, süre; sonuçta yanlışları tekrar çözme
- **Sorular:** 396 çıkmış soru, arama, filtre, cevapları gizleme
- **İlerleme:** ders bazında öğrenilen soru, isabet, test geçmişi
- Telefona uygulama olarak eklenebilir, internet olmadan da çalışır (PWA)

İlerleme yalnızca kullanılan cihazın tarayıcısında saklanır.
