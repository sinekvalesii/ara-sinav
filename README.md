# Ara Sınav Çalışma — 4 Ders

AÖF Lojistik ara sınavı için çalışma sitesi: Uluslararası Lojistik, Gümrük Mevzuatı, Hukukun Temel Kavramları, Türk Dili I.

- **Ezber notları:** ünite ünite önemli noktalar
- **Tekrar edenler:** çıkmış sorular, kaç sınavda çıktığına göre sıralı, cevaplı
- **Test / Tümü karışık:** şıkları karıştırılmış soru çözme
- **Yanlışlarım:** yanlış yapılan sorular (tarayıcıda saklanır)
